# cluster

Випускний проєкт (11 клас): легка система розподілених обчислень для локальної мережі.

Програма дозволяє об'єднати вільні ноутбуки або ПК в одній локальній мережі (наприклад, у шкільному кабінеті інформатики чи вдома). Один комп'ютер працює як контролер (головний вузол), інші підключаються як воркери та виконують задачі: запуск скриптів і проєктів різними мовами, паралельна обробка файлів, локальний веб-хостинг і пошук дублікатів.

## Як встановити та запустити (для перевірки)

### Спосіб 1. Через установник (найпростіше, Python не потрібен)
1. Завантажте `cluster-setup.exe` зі сторінки **Releases** на GitHub.
2. Запустіть установник (працює без прав адміністратора, ставить у `%LOCALAPPDATA%\cluster`, створює ярлики та копіює папку `examples`).
3. Натисніть **Launch Demo** — програма одразу підніме 1 контролер та 2 локальних воркери на одному ПК, щоб можна було перевірити всі функції без другого комп'ютера.

### Спосіб 2. Із вихідного коду
Потрібен Python 3.10+:
```bash
pip install -r requirements.txt
python run.py
```

### Спосіб 3. Перезібрати `.exe` самостійно
```bat
build_exe.bat
```
Скрипт збере `dist\cluster.exe` та установник `dist\cluster-setup.exe`.

## Як підключити кілька ПК у мережі

1. На головному ПК запустіть `cluster` та оберіть **Controller** (порт за замовчуванням `8000`).
2. На інших ПК оберіть **Worker** — програма сама просканує локальну мережу через UDP та покаже знайдений контролер у списку `LAN`.
3. Підключитися можна двома способами:
   - Натиснути **Request Access** (без коду) — на контролері з'явиться запит із кнопками **Approve / Decline**.
   - Або ввести короткий 6-значний код (команда `/invite` на контролері).

Воркери автоматично перевіряють навантаження процесора, вільну пам'ять і заряд батареї (правила зберігаються в `data/sharing.json`), щоб не гальмувати роботу власника ПК.

## Для чого можна використовувати та які команди є

Усі команди вводяться в консолі зліва (або відкриваються кнопками під нею):

| Команда | Для чого потрібна | Приклад |
|---|---|---|
| `/run` | Запустити один файл або цілу папку проєкту (Python, Node.js, C/C++, Go, Java, PowerShell, Bash) на найменш завантаженому вільному вузлі, де є потрібне середовище чи GPU. | `/run C:\proj\train.py` або `/run C:\app :: node index.js` |
| `/map` | Роздати папку з файлами по **всіх** вільних воркерах одночасно й виконати вказаний скрипт/команду для кожного файлу паралельно (з таймаутом оренди 20 с і повтором при збої). | `/map C:\texts :: C:\scripts\process.py` |
| `/host` | Запустити статичний сайт (HTML/CSS/JS) або веб-сервер на одному з воркерів і отримати посилання `http://IP:ПОРТ`. | `/host 8080 C:\my_site` |
| `/stop` | Зупинити запущений через `/host` сервіс. | `/stop 1` |
| `/batch` | Розподілений аналіз текстових файлів (`.txt`, `.md`, `.log`): підрахунок слів, рядків і пошук побайтових дублікатів за SHA-256. | `/batch C:\docs` |
| `/sample` | Швидкий тест на 24 згенерованих файлах (має знайти 12 груп дублікатів). | `/sample` |
| `/report` | Експорт результатів останнього або вибраного пакета в JSON, CSV та HTML-звіт (одразу відкривається у браузері). | `/report` |
| `/demo` | Відкрити вікно готових прикладів для демонстрації (`/demo math` — швидкий математичний тест). | `/demo` |
| `/invite` | Створити 6-значний код і `cluster://` посилання на 5 хвилин (одразу копіюється в буфер). | `/invite` |
| `/nodes` | Показати підключені вузли, ресурси та знайдені середовища (`python`, `node`, `gcc`, `ollama`, `gpu` тощо). | `/nodes` |
| `/revoke` | Відкликати доступ конкретного воркера та повернути його незавершені задачі в чергу. | `/revoke node-a1b2` |

## Готові приклади в `/demo` та папці `examples`

Щоб не писати тестові файли вручну, у команді `/demo` є 5 готових сценаріїв:
1. **AI Training** (`examples/ai_train_demo.py`) — навчання лінійної моделі градієнтним спуском на вільному воркере.
2. **Monte Carlo Pi** (`examples/monte_carlo_pi.py`) — наближене обчислення числа Пі методом Монте-Карло (800 000 точок).
3. **Parallel Map** (`examples/parallel_texts` + `examples/text_stats_map.py`) — паралельний розбір 6 файлів скриптом одразу на всіх воркерах.
4. **Static Website Hosting** (`examples/site_demo`) — розгортання веб-сторінки на воркері через `/host`.
5. **Text & Duplicate Check** (`/sample`) — пакет із 24 файлів для перевірки підрахунку слів, дублікатів і HTML-звіту.

Якщо на комп'ютерах стоїть Ollama з локальною LLM (наприклад, `qwen`), `/nodes` покаже наявність `ollama` та `gpu`, а через `/map` можна паралельно проганяти папку запитів одразу на кількох ПК у локальній мережі.

## Безпека та чесні обмеження

- Весь обмін даними між контролером і воркерами йде через HTTPS (TLS) з перевіркою SHA-256 відбитка сертифіката (certificate pinning) та індивідуальними токенами пристроїв.
- Черга задач і стан зберігаються в SQLite (`data/swarm.db`, `data/cluster.db`), тому незавершені файли не губляться при перезапуску або відключенні одного з ПК.
- Програма розподіляє окремі задачі та незалежні файли; вона не об'єднує фізичну оперативну чи відеопам'ять кількох комп'ютерів в одну спільну пам'ять.

## Структура проєкту

```text
cluster/
├── __init__.py
├── controller.py   — HTTPS-сервер, UDP-маяк, планувальник Best-Fit
├── worker.py       — підключення до контролера, виконання задач і хостинг
├── tasks.py        — черга SQLite, оренда задач (20 с), упаковка проєктів
├── security.py     — TLS-сертифікати, pinning, одноразові коди та запити доступу
├── system.py       — моніторинг CPU/RAM/диска/батареї та пошук мов/GPU
├── report.py       — збереження звітів у JSON, CSV та HTML
├── lang.py         — локалізація інтерфейсу (EN / UA)
└── gui.py          — графічний інтерфейс (термінал зліва, статистика й вузли справа)
examples/           — приклади задач і демо-сайт
tests/              — автотести (unittest)
installer.py        — вихідний код установника cluster-setup.exe
run.py              — точка входу програми
```
