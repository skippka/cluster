# Cluster — розподілені обчислення в локальній мережі

Проект для випускної роботи (11 клас).

Програма дозволяє об'єднати комп'ютери чи ноутбуки у звичайній локальній мережі (наприклад, у шкільному класі інформатики або вдома) для розподіленої обробки завдань. Головний комп'ютер (контролер) розбиває великий пакет файлів на частини і роздає іншим комп'ютерам (воркерам), які паралельно рахують слова, рядки, хеші та шукають дублікати.

## Можливості

- Простий запуск: один скрипт `start_cluster.bat` сам ставить віртуальне оточення і залежності під Windows.
- Безпечне підключення: з'єднання шифрується через TLS, використовуються одноразові інвайти (діють 5 хвилин), а клієнт перевіряє відбиток сертифіката (certificate pinning), щоб ніхто в тій самій мережі не міг перехопити дані.
- Захист ресурсів комп'ютера: на кожному воркері можна налаштувати, скільки оперативної пам'яті виділяти (наприклад, залишити 2 ГБ для себе). Якщо процесор зайнятий користувачем або ноутбук працює від слабкої батареї — обчислення автоматично ставляться на паузу.
- Стійкість до збоїв: завдання видаються з таймаутом (оренда на 20 секунд). Якщо якийсь комп'ютер раптово вимкнувся або відпав Wi-Fi, контролер автоматично передає завдання іншому вільному воркеру.
- Збереження прогресу: історія та черга зберігаються в базі SQLite, тому при перезапуску сервера завдання не губляться.
- Звіти: результати зберігаються у форматах JSON та CSV.

## Швидкий запуск

### Windows
Запустіть файл `start_cluster.bat`. При першому запуску автоматично створиться папка `.venv`, встановляться бібліотеки `cryptography` і `psutil` та відкриється меню.

### Linux / macOS (або вручну через консоль)
```bash
python -m venv .venv
source .venv/bin/activate  # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

## Як користуватися

1. **Запустити контролер (головний ПК):**
   - У меню вибрати `[1] Контролер`.
   - Вказати порт (за замовчуванням 8000).
   - Ввести команду `invite` — з'явиться посилання із запрошенням (діє 5 хвилин).

2. **Підключити воркер (інші ПК):**
   - На іншому комп'ютері запустити програму та вибрати `[2] Воркер`.
   - Вставити посилання `cluster://...`.
   - Ввести назву комп'ютера та вибрати профіль ресурсів (наприклад, збалансований).

3. **Запустити обробку:**
   - На контролері ввести `sample` (згенеpyє тестові тексти і роздасть по воркерах) або `batch <шлях до папки>` (для власних файлів .txt, .md, .log).
   - За допомогою команди `watch` можна дивитися навантаження і прогрес у реальному часі.
   - Команда `report` збереже готовий звіт із результатами в папку `data/reports/`.

## Команди консолі контролера

- `nodes` або `dashboard` — перегляд списку підключених воркерів та їх ресурсів.
- `watch` — живий моніторинг (оновлюється раз на 2 секунди, вихід по Ctrl+C).
- `invite` — згенерувати одноразовий код підключення для нового ПК.
- `devices` — список зареєстрованих пристроїв.
- `revoke` — відкликати доступ у пристрою (його поточні завдання повернуться в чергу).
- `sample` — запустити тест із 24 згенерованими файлами.
- `batch` — відправити на обробку свою папку з файлами.
- `batches` — переглянути статус виконання пакетів.
- `report` — експортувати результати у CSV та JSON.
- `explain` — подивитися, як планувальник оцінює вузли і чому вибирає саме їх.
- `demo` — запуск тестового математичного обчислення на вільному вузлі.
- `clear` — очистити екран.
- `exit` — зупинити контролер.

## Налаштування безпеки та ресурсів

Воркер зберігає свої правила у файлі `data/sharing.json`. Він перевіряє їх перед тим, як взяти будь-яке завдання:
- `reserve_ram_gb`: скільки оперативної пам'яті зарезервувати для потреб власника ПК (за замовчуванням 2 ГБ).
- `max_host_cpu`: поріг навантаження процесора (за замовчуванням 75%). Якщо комп'ютер зайнятий, завдання не беруться.
- `minimum_battery` та `ac_only`: захист акумулятора ноутбука (не розряджати батарею нижче 35% або працювати тільки від розетки).

## Тести

Для перевірки роботи системи написано 27 тестів (модульні та інтеграційні):
```bash
python -m unittest discover -s tests -v
```

Також можна запустити демонстраційний сценарій, який імітує роботу двох окремих воркерів на одному ПК:
```bash
python examples/demo_local.py
```

## Структура файлів

- `start_cluster.bat` — скрипт швидкого запуску для Windows.
- `run.py` — головний файл для запуску.
- `requirements.txt` — потрібні бібліотеки (`cryptography`, `psutil`).
- `src/cluster/` — вихідний код програми:
  - `cli.py` — текстове стартове меню.
  - `ui.py` — кольорове оформлення консолі.
  - `controller.py` — сервер контролера і робота з командами.
  - `worker.py` — клієнт воркера і виконання завдань.
  - `scheduler.py` — планувальник (алгоритм Best-Fit).
  - `swarm.py` — черга файлів, оренда завдань і робота з базою SQLite.
  - `sharing.py` — перевірка батареї та лімітів ресурсів на воркері.
  - `trust.py` — генерація сертифікатів TLS, відбитки (pinning) та токени.
  - `corpus.py` — підрахунок слів, рядків і пошук дублікатів.
  - `system_info.py` — збір інформації про CPU, пам'ять та диск.
- `tests/` — автотести перевірки мережі, черги та безпеки.
- `examples/demo_local.py` — тест запуску двох локальних воркерів.
